# Getting Started with DLX Studios

Welcome to DLX Studios! This guide will help you get started in just 5 minutes.

## Quick Start

### 1. First Launch

When you first open DLX Studios, you'll see the Welcome Wizard. This will guide you through:

- Setting up your profile
- Connecting your first service
- Generating your first piece of content
- Exploring key features

**💡 Tip:** You can skip the wizard if you're a power user, but we recommend completing it to understand the platform.

### 2. Connect Your Services

Go to **Settings → Credentials** and connect your services:

#### Stripe (Revenue Tracking)
1. Log in to [Stripe Dashboard](https://dashboard.stripe.com)
2. Go to **Developers → API Keys**
3. Copy your **Secret Key** (starts with `sk_`)
4. Paste it in DLX under Stripe settings
5. Click **Save**

#### WordPress (Content Publishing)
1. Go to your WordPress admin
2. Navigate to **Users → Profile**
3. Scroll to **Application Passwords**
4. Generate a new password
5. Enter your site URL and password in DLX

#### OpenAI (AI Content Generation)
1. Get your API key from [OpenAI](https://platform.openai.com)
2. Add it in DLX settings
3. Start generating content!

### 3. Generate Your First Content

1. Click **Creator** in the sidebar
2. Choose a template (Blog Post, Social Media, etc.)
3. Enter your topic
4. Click **Generate**
5. Review and edit the generated content
6. Publish or save for later

### 4. Track Your Revenue

Once you've connected Stripe or other payment services:

- View real-time revenue in the **Dashboard**
- See revenue breakdown by source
- Export data for accounting
- Set up automated reports

### 5. Set Up Automation

Create your first automated workflow:

1. Go to **Workflows**
2. Click **New Workflow**
3. Choose a trigger (Schedule, Event, etc.)
4. Add actions (Generate, Publish, etc.)
5. Activate and let it run 24/7
